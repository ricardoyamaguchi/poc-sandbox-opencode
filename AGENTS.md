# AGENTS.md

iOS SwiftUI app (`PocSandbox`) using CocoaPods. No tests, CI, lint, or formatter config exist.

## Generated project — do not hand-edit
- `PocSandbox.xcodeproj` is generated by **xcodegen** from `project.yml`. Never edit it directly; edit `project.yml` and regenerate.
- Always open/build the **workspace** `PocSandbox.xcworkspace` (CocoaPods), never `PocSandbox.xcodeproj`.
- After changing `project.yml`, `Podfile`, or adding/removing source files: `make generate` (runs `xcodegen generate && pod install`).
- Source files under `PocSandbox/` are picked up automatically (xcodegen `sources: PocSandbox`), so new `.swift` files need no project edits.

## Makefile
- `make help` — lists targets; prefer `make` over raw commands.
- `make generate` — regenerates `PocSandbox.xcodeproj` and runs `pod install`.
- `make debug` / `make release` — build the workspace in that configuration.
- `make build` — build with current `CONFIGURATION` (default `Debug`).
- `make run` — build, boot the simulator, install and launch.
- `make clean` / `make distclean` — remove local build output / all generated files.
- Override variables: `make run SIMULATOR_NAME="iPhone 17 Pro" BUNDLE_ID=...`.

## Scripts
- `./scripts/generate.sh` — regenerates `PocSandbox.xcodeproj` and runs `pod install`.
- `./scripts/build.sh` — builds the workspace (override `SIMULATOR_NAME`, `CONFIGURATION`).
- `./scripts/run.sh` — builds, boots the simulator, installs and launches the app.

## Build
```
make build
```
- Equivalent raw command: `xcodebuild -workspace PocSandbox.xcworkspace -scheme PocSandbox -destination 'platform=iOS Simulator,name=iPhone 17' build`.
- Must specify a destination; the default fails on this machine.
- Only scheme to build is `PocSandbox` (other schemes are pod-generated).

## Toolchain quirks
- Xcode 26.3 SDK is iOS 26.2; the app deployment target is iOS 17.0 (`project.yml`).
- The installed simulator runtime is iOS 26.3 (`iPhone 17`, `iPhone Air`). Older runtimes (17.x/18.x) are present but not matched by default.
- If `xcodebuild` reports `iOS <ver> is not installed` or "Supported platforms ... is empty", the iOS platform component is missing: run `xcodebuild -downloadPlatform iOS` (large download).

## Dependencies
- Managed by CocoaPods via `Podfile` (currently Alamofire). Pin versions there; `Podfile.lock` is checked in.
